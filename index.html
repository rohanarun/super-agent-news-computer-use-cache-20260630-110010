How Super’s computer-use cache works

1) Real computer actions

Super controls a real browser or desktop to complete multi-step tasks that APIs can’t cover.

2) Action trace capture

Each click, keystroke, selector, and wait is recorded as an auditable trace for accountability.

3) Cache & reuse

The trace is normalized and saved as a reusable computer-use cache for the same job.

4) Cheaper repeats

On the next run, Super replays the cache with fallbacks, reducing tokens and flakiness.
